# Data Directory

The raw dataset is **not included** in this repository to keep the repo size small.

## Download the dataset

1. Go to [Kaggle — Sample Superstore Dataset](https://www.kaggle.com/datasets/vivek468/superstore-dataset-final)
2. Download `Sample - Superstore.csv`
3. Place it in this `data/` directory:

```
data/
└── Sample - Superstore.csv   ← place file here
```

## Notes

- Encoding: `latin-1` (ISO-8859-1) — make sure to specify this when reading with pandas
- The cleaned version (`Superstore_Cleaned.csv`) is generated automatically when you run `superstore_eda_report.ipynb` Section 2
- The SQLite database (`superstore.db`) is generated by `1_data_cleaning.ipynb`
